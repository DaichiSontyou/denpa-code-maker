# 電波人間コードメーカー

3DS「電波人間のRPG FREE!」の、コード入力で使うコードを作ったり調べたりするWebツールです。
ブラウザで `index.html` を開くだけで動きます。インストールやサーバーは要りません。

**今すぐ使う: https://daichisontyou.github.io/denpa-code-maker/**

リポジトリ: https://github.com/DaichiSontyou/denpa-code-maker

**非公式のツールです。** ゲームの更新データ(Ver.1.17)を調べて、計算のしかたを再現しています。

## できること

- **不具合修正コード**: サポート窓口が出していたコード(12種類)を作ります。サポート番号を入れると、その人用のコードになります。
- **共通コード50件**: 「せってい」の「コード入力」で使える50件の一覧と、そのコードを作ります。
  公式に配られたコード29件は、そのまま見比べられます。
- **コードを調べる**: 16文字のコードを読み取って、種類・必要バージョン・中身を表示します。

## 使い方

1. 上のリンクを開きます。ダウンロードして使う場合は、`index.html` をブラウザで開きます。
2. タブを選びます。
3. 作ったコードをコピーして、ゲームのコード入力に打ちます。

サポート番号は、ゲームの「せってい」の「サポート番号」に出る16けたです。
まだ番号をもらっていない場合は、空欄のままで作れます(0として計算します)。

## 必要バージョンについて

コードには「このバージョン以上のゲームで使える」という印が入っています。

- **どの版でも使える(0.0.0)**: 初期値です。どのバージョンでも、版のチェックを通ります。
- **最終版 1.17.0 以上**: 公式コードと同じ印です。「公式の版にそろえる」を選ぶと、公式コードと同じ文字列になります。
- **版を指定する**: 好きな版を入れられます。ゲームの最終版(1.17.0)より新しい版を入れると、最終版では受け付けられません。

## できないこと

- ゲームの中にある効果しか作れません。好きなフラグやアイテムを指定するコードは作れません。
- 作ったコードを実機に入力して動くかどうかは、まだ確かめていません。
  公式コード29件を読み取って計算が合うことは確認しています。
- 通信が必要なコード(サーバーが確認するタイプ)は、最終版では使えません。

## ファイル

- `index.html` : 画面
- `denpa-core.js` : コードの計算部分(ブラウザでもNodeでも動きます)
